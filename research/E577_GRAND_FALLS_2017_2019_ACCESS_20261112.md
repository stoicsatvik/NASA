# E577 — independent Grand Falls 2017–2019 data-access probe

Date: 12 November 2026

## Question

Can the separate USGS Grand Falls Dune Field 2017–2019 sediment-transport release provide a small, anonymous, provenance-pinned field-data sample, without repeating the failed 2022–2023 photogrammetry-item routes?

## Why this is a distinct experiment

- Source: USGS, *Grand Falls, Arizona: Dune Field Sand Transport 2017–2019*, DOI [10.5066/P9IYGDGQ](https://doi.org/10.5066/P9IYGDGQ).
- ScienceBase item ID resolved from the official USGS Asset Identifier link: \`5f6e51f182ce38aaa24a73a7\`.
- The release covers 7 February 2017–22 May 2019 and describes 10-second wind/sediment-sensor logs, three anemometer heights, weighing BSNE samplers and 15-minute xBSNE imagery.
- This is a separate data release and ScienceBase item from the 2022–2023 photogrammetry item rejected by E536/E538/E540. No alternate URL is being guessed for the old item.

## Frozen access protocol

- Anonymous HTTPS only; no cookies, account credentials, tokens, API keys or contact.
- Inspect only the exact ScienceBase item metadata, with a 5 MB response cap.
- Select the smallest metadata-listed CSV/TXT/TSV/DAT/ZIP with an explicit \`downloadUri\` and catalogue size at most 5 MB.
- Request a bounded 4 KiB byte range. Require HTTP 206, exact Content-Range, and agreement with the catalogue file size.
- Only if the file is at most 5 MB and the range is valid, download that one file and compute SHA-256.
- For delimited data, retain only column names, row count, time bounds and aggregate summaries for wind/sediment/temperature/pressure fields. For ZIP, inspect the smallest delimited member under the same cap.
- Do not store raw rows, raw file bytes, raw URLs, signed query values or field coordinates in the receipt. The only output is a short-lived Actions artifact.
- Reject redirects outside the pinned ScienceBase/S3 host allowlist.
